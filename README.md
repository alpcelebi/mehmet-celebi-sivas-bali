# Mehmet ÇELEBİ Sivas Balı - E-Ticaret & Tanıtım Web Sitesi

Sivas'ın yüksek rakımlı yaylalarından sofralara uzanan %100 doğal, katkısız ve saf bal üreticisi **Mehmet ÇELEBİ** için özel olarak hazırlanmış modern, şık ve mobil uyumlu React + Vite web uygulaması.

---

## 🌟 Öne Çıkan Özellikler

1. **Renk Paleti & Tasarım:**
   - Bal Sarısı / Amber tonları (`#F59E0B`, `#D97706`), Derin Siyah / Gece Mavisi (`#0F172A`, `#1E293B`, `#0B1120`) ve Saf Beyaz (`#FFFFFF`).
   - Bal peteği desenleri, cam efekti (glassmorphism) ve altın ışıma efektleri.
2. **Karanlık (Dark) ve Aydınlık (Light) Tema Desteği:**
   - Navbar üzerinde Güneş ve Ay ikonlu tek tıkla mod değiştirici.
   - `localStorage` desteği ile kullanıcının tema tercihi hatırlanır.
3. **Dinamik WhatsApp Sipariş Entegrasyonu:**
   - WhatsApp Sipariş Numarası: `905441194066`
   - Her ürün kartı için otomatik dinamik mesaj:  
     `Merhaba Mehmet Bey, web sitenizden [Ürün Adı] sipariş vermek istiyorum. Bilgi alabilir miyim?`
4. **Modüler Bileşen Mimarisi:**
   - `Navbar`: Responsive menü, logo ve tema değiştirme butonu.
   - `Hero`: Sivas yayla balı manşeti, güven rozetleri ve ana CTA butonları.
   - `Features`: 6 maddelik doğallık ve arıcılık ilkeleri.
   - `Products`: 850g Kavanoz, 1500g Aile Boyu, Karakovan ve Petek Bal kartları.
   - `About`: Mehmet ÇELEBİ'nin samimi arıcılık hikayesi ve felsefesi.
   - `FloraGuide`: Sivas Geveni, Dağ Kekiği ve kristalleşme bilgilendirme alanı.
   - `Testimonials`: Türkiye genelinden doğrulanmış müşteri yorumları.
   - `Faq`: Kargo, doğallık ve tüketim rehberi akordiyonu.
   - `Contact`: İletişim detayları ve anlık WhatsApp sipariş mesajı sihirbazı.
   - `Footer`: Adres, telefon ve telif hakları.
   - `FloatingWhatsApp`: Sağ alt köşede sabit, parlayan WhatsApp butonu.

## 🚀 Kurulum ve Çalıştırma

Projeyi yerel ortamınızda çalıştırmak için:

```bash
# Bağımlılıkları yükleyin
npm install

# Geliştirme sunucusunu başlatın
npm run dev
```

Tarayıcınızda açın:
```
http://localhost:5173/
```

Üretim sürümünü derlemek için:
```bash
npm run build
```
